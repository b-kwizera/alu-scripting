1-top_ten.py: Queries the Reddit API and prints the titles of the first 10 hot posts for a given subreddit. Prints None if subreddit is invalid.
2-recurse.py: Recursively queries the Reddit API and returns a list of all hot article titles for a given subreddit. Returns None if the subreddit is invalid.
3-count.py: Reads from standard input and counts the number of lines, printing the total count.
